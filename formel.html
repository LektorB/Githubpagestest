🧪 Formel-guide for Kjemi i Naturfag (Word og OneNote)

Å skrive kjemiske formler, ioner og reaksjonsligninger digitalt kan virke knotete om man må klikke på knapper for senket og hevet skrift for hvert enkelt tegn. Med Word og OneNote sitt innebygde formelverktøy kan du skrive alt fra molekyler til kjemiske utregninger lynraskt med tastaturet!

🚀 Slik åpner du formelverktøyet

Sett markøren der du vil ha formelen og trykk på hurtigtasten for ditt operativsystem og program:

Program Plattform Hurtigtast
Microsoft Word PC (Windows) Alt + + (eller Alt + Shift + 0)
Mac Control + = (eller Option + Command + =)
Microsoft OneNote PC (Windows) Alt + =
Mac Control + =
💡 Profftips for rett skrift i kjemi: Word vil automatisk sette alt du skriver i en formel i kursiv (som passer for matematiske variabler). Kjemiske symboler (som H, O, Na) skal ikke være i kursiv.
Løsning: Sett anførselstegn rundt teksten eller kjemisymbolet! Skriver du "H"_2"O", blir det stående helt rett uten kursiv. Du kan også trykke på «Vanlig tekst» (Normal Text) i formelmenyen øverst.

⚗️ 1. Kjemiske formler (Senket og hevet skrift)

Når formelboksen er aktiv, bruker du _ for senket skrift (antall atomer) og ^ for hevet skrift (ladning/potens). Trykk mellomrom etter koden for at Word skal formatere det.

Molekylformler (Senket skrift)

  • Vann: Skriv H_2O + Mellomrom → H2O
  • Karbondioksid: Skriv CO_2 + Mellomrom → CO2
  • Glukose: Skriv C_6H_12O_6 (bruk parentes om nødvendig: C_6H_(12)O_6) → C6H12O6

Ioner og ladninger (Hevet skrift eller kombinasjon)

  • Natriumion: Skriv Na^+ + Mellomrom → Na+
  • Kloridion: Skriv Cl^- + Mellomrom → Cl-
  • Oksidion: Skriv O^(2-) + Mellomrom → O2-
  • Sulfation (både senket og hevet): Skriv SO_4^(2-) + Mellomrom → SO42-
  • Oksoniumion: Skriv H_3O^+ + Mellomrom → H3O+

Isotoper og stråling (Naturfag tema: Radioaktivitet)

For isotoper må du ha hevet og senket skrift foran grunnstofftegnet:

  • Karbon-14: Skriv _6^14 "C" → 146C
  • Uran-238: Skriv _92^238 "U" → 23892U
  • Alfa-partikkel (Heliumkjerne): Skriv _2^4 \alpha eller _2^4 "He" → 42He

🔄 2. Reaksjonsligninger, piler og tilstandsformer

I kjemi binder vi reaksjonsligninger sammen med piler og angir tilstandsformene til stoffene.

Reaksjonspiler

Type pil Kode i Word/OneNote Resultat
Reaksjonspil (fullstendig) \rightarrow eller -> + Mellomrom →
Reversibel reaksjon (likevekt) \leftrightarrow eller \equil + Mellomrom •→ / ⇌
Reaksjon med varme/energi over pilen \above(->,\Delta) + Mellomrom → (med Δ over)

Tilstandsformer Viktig i Naturfag

Tilstandsformer skrives i parentes etter stoffet. Husk å skrive dem i vanlig tekst (ikke kursiv) ved å bruke anførselstegn:

  • Fast stoff (solid): "(s)" → (s)
  • Væske (liquid): "(l)" → (l)
  • Gass (gas): "(g)" → (g)
  • Løst i vann (aqueous): "(aq)" → (aq)

Komplett eksempel på reaksjonsligning:

For å skrive knallgassreaksjonen: 2H2(g) + O2(g) → 2H2O(l)

Skriv dette i formelboksen:
2"H"_2"(g)" + "O"_2"(g)" \rightarrow 2"H"_2"O(l)"

📐 3. Støkiometri, regneformler og enheter

Når du gjør kjemiske beregninger i Naturfag (som mol, masse, molar masse og konsentrasjon), trenger du brøker og enheter.

Sentrale formler i Naturfag-kjemi

Størrelse Formel-kode Visning
Stoffmengde: $n = \frac{m}{M}$ n = m/M + Mellomrom n = mM
Molar konsentrasjon: $c = \frac{n}{V}$ c = n/V + Mellomrom c = nV
Massetetthet: $\rho = \frac{m}{V}$ \rho = m/V + Mellomrom ρ = mV
Masseprosent: $\text{Masse}\% = \frac{m_{\text{stoff}}}{m_{\text{total}}} \cdot 100\%$ "Masse%" = (m_stoff)/(m_total) * 100% Masse% = mstoffmtotal · 100%

Nyttige kjemiske enheter og greske bokstaver

  • Molar masse (g/mol): Skriv "g/mol" eller "g" \cdot "mol"^-1 → g/mol eller g·mol-1
  • Konsentrasjon (mol/L): Skriv "mol/L" eller "M" → mol/L eller M
  • Temperatur og endring (Δ): Skriv \Delta T for å få ΔT. For grader Celsius: skriv 100^\circ "C" for å få 100° C.
  • Greske tegn i kjemi/stråling:
    • \alpha → α (Alfa-stråling)
    • \beta → β (Beta-stråling)
    • \gamma → γ (Gamma-stråling)
    • \rho → ρ (Tetthet / Rho)
💡 Eksempel på komplett utregning i Word/OneNote:
n = m/M = (5.00 " g")/(58.44 " g/mol") = 0.0855 " mol"

Vil bli seende slik ut:
n = mM = 5.00 g58.44 g/mol = 0.0855 mol
