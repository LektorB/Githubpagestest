Skisser rasjonale funksjoner

Finn nøkkelpunktene før du tegner.

f(x) = ax + bcx + d
Hovedtilfellet: ekte hyperbel

c ≠ 0   og   ad − bc ≠ 0

Særtilfellet med hull står nederst.

1 Nullpunkt

Sett telleren lik null. Sjekk nevneren!

ax + b = 0   ⇒   x = −ba

Krever a ≠ 0 og at nevneren ikke er null.

Hvis a = 0: ingen nullpunkter i hovedtilfellet.

2 Skjæring med y-aksen

Sett x = 0 og regn ut f(0).

f(0) = bd

Punktet er (0; b/d), dersom d ≠ 0.

Hvis d = 0: ingen skjæring med y-aksen.

3 Loddrett asymptote

Sett nevneren lik null.

cx + d = 0   ⇒   x = −dc

Hvis telleren ≠ 0 her: loddrett asymptote.

Df = ℝ ∖ {−d/c}

Definisjonsmengden gjelder hovedtilfellet.

4 Vannrett asymptote

Sammenlikn leddene med høyest grad.

ax + bcx + d ≈ axcx = ac
y = ac

Tilnærmingen gjelder når x blir svært stor i positiv eller negativ retning (x → ±∞).

Vf = ℝ ∖ {a/c}

Den vannrette asymptotens y-verdi er utelatt fra verdimengden i hovedtilfellet.

Slik tegner du skissen

  1. Tegn asymptotene stiplet i et stort koordinatsystem. Marker akseskjæringene.
  2. Regn ut minst ett ekstra punkt på hver side av den loddrette asymptoten.
  3. Tegn to grener som nærmer seg asymptotene. De krysser dem ikke i hovedtilfellet.

EKSEMPEL

f(x) = 2x + 1x − 1

Nullpunkt: (−0,5; 0)
Skjæring med y-aksen: (0; −1)
Asymptoter: x = 1 og y = 2

Grafen er punktsymmetrisk om asymptotenes skjæringspunkt S = (1; 2).

S = (−d/c; a/c)

Pass på: hull eller asymptote?

Hvis både teller og nevner blir 0 ved x = −d/c, er det et hull. Da er ad − bc = 0.

Uttrykket forkortes til f(x) = a/c, men x = −d/c er fortsatt utelatt. Grafen er en vannrett linje med hull i (−d/c; a/c). Ingen loddrett asymptote.

I dette særtilfellet er Vf = {a/c}. I spillet får du alltid en ekte hyperbel.

Forutsetning: c ≠ 0. Bruk alltid den opprinnelige nevneren for å finne definisjonsmengden. Basert på det vedlagte huskearket.
